# 1970年代电网调度控制室 — 场景规格

## 电网 GRID 模拟盘（按图中黄色盘还原）
| 元素 | 规格 |
|---|---|
| 盘面 | 明黄底色 |
| 电网单线图 | 黑色单线绘制 |
| 圆形指示灯 | 红色 |
| 方形指示灯 | 琥珀色 |
| 选择开关 | 黑色旋钮，带刻度盘 |
| 文字标注 | 德文功能标签 |
> 可作墙面或台体立面的模拟盘，位置与图一致。

## 材质（年代感中性米灰色调）
- 墙面 / 吊顶：浅色哑光
- 操作台 / 控制台：浅灰或米色金属 + 层压饰面
- 仪表 / 指示盘：深色边框 + 浅色面
- 各类指示灯：自发光（emissive）材质

## 灯光
- 吊顶日光灯 / 面板灯（fluorescent troffer），做均匀主照明
- 整体略带年代感的室内氛围

## 相机（两个机位）
| 机位 | 用途 |
|---|---|
| 全景 | 还原原照片透视，略俯视，交代房间整体关系 |
| 特写 | 对准斜面控制台 / GRID 模拟盘，看清旋钮与指示灯 |

## 渲染设置
- 引擎：Cycles，开启降噪
- 色彩管理：Filmic
- 输出：PNG（分辨率与张数见正文）
- 集合按部件规范命名后保存 .blend
