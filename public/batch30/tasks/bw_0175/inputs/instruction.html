Query · 原始任务

我在写一篇关于城市空中交通概念设计的研究论文，想配一张单座 eVTOL 空中出租车（四涵道倾转风扇布局）的效果主图，这张图后面也要拿到课堂上给学生讲整机结构和倾转原理，所以各部件的装配和功能关系一定要能拆开讲清楚、不能糊在一块。

整机按毫米建模，整机前后总长 4800、翼展（含涵道最外缘）3600、停机总高 1650。座舱主体长度约 3200、最大宽 1500、最大高 1300；其余尺寸按 scene_spec.md。核心部件有五个：泪滴形单体壳的座舱主体、前段可透视的座舱盖、前左/前右/后左/后右四组对称的涵道风扇、连接机身与涵道的倾转臂，以及一对弓形着陆滑橇。倾转臂本图统一摆成 15° 前倾的巡航姿态。周边就是个干净的影棚环境，别加多余陈设。

重点是让四涵道倾转的整体布局、以及各部件之间的连接关系看得清清楚楚——主体不能被反光或背景盖住，整机比例要准，别让读者对尺寸产生误判。配色和各材质的质感区分你来把握，几种金属灰别弄得太接近、糊到一起分不出来；未标尺寸按同类对象常规比例估算就行。

坐标系约定、逐件尺寸、每项 PBR 材质、三点布光的角度与色温、相机镜头和渲染设置我都整理在附带的 `scene_spec.md` 里了，按那个来。最后给我出一张 3840×2160 的宣传主图，Blender 工程也留着，后面往论文和课件里放时可能还要换机位、调角度。

# 单座 eVTOL 空中出租车 — 场景规格

## 坐标系约定
- 原点：机身几何中心
- 轴向：X 向前、Y 向左、Z 向上
- 单位：毫米

## 部件清单（≥5 个独立部件，体现装配/功能关系）
| 部件 | 关键尺寸 | 说明 |
|---|---|---|
| 座舱主体 | 长约 3200、最大宽 1500、最大高 1300 | 泪滴形单体壳，前段为可透视座舱盖 |
| 座舱盖 | 与壳体沿分模线留 5mm 缝隙 | 熏黑渐变夹层玻璃，后缘有可见开启铰链 |
| 涵道风扇 ×4 | 外径 900、内径 820（壁厚 40）、桨毂 180、每涵道 5 片桨叶 | 前左/前右/后左/后右对称；四涵道中心位于 X=±1400、Y=±1350 |
| 倾转臂 | 翼型截面 120×60 | 连接机身与涵道，绕 Y 轴 0–90° 倾转（悬停 90°、巡航 0°），本图统一 15° 前倾 |
| 着陆滑橇 ×1 对 | 轨距 1400、离地间隙 260 | 碳纤维弓形滑橇 |

## 材质（全 PBR）
- 壳体：珍珠白汽车漆（底色 + 金属薄片 + 清漆），粗糙度约 0.15
- 座舱盖：玻璃 BSDF，透射，IOR 1.52，用体积吸收做出烟灰色调
- 涵道外壳：3K 斜纹编织碳纤维
- 桨叶：阳极氧化深钛灰铝合金，各向异性金属
- 倾转臂：亚光深空灰
- 滑橇：拉丝铝

## 场景与地面
- 浅灰无缝影棚弧形背景地面，带轻微反射

## 灯光（HDRI 影棚环境 + 三点布光）
- 主光：左前上方大面积柔光箱，5500K
- 侧逆光：勾勒轮廓
- 底部补光：微弱，避免暗部死黑

## 相机
| 项 | 值 |
|---|---|
| 视角 | 3/4 前侧英雄视角 |
| 机位高度 | 约 1200（略低于车高，形成轻微仰视） |
| 焦距 | 50mm 全画幅等效 |
| 光圈 | f/4 |
| 传感器 | 36mm |

## 渲染
- 引擎：Cycles，采样 2048，OptiX 降噪
- 色彩管理：AgX，中性对比
- 输出：16-bit PNG，并保存 .blend
