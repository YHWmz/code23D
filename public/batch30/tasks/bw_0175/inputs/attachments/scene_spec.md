# 单座 eVTOL 空中出租车 — 场景规格

## 坐标系约定
- 原点：机身几何中心
- 轴向：X 向前、Y 向左、Z 向上
- 单位：毫米

## 部件清单（≥5 个独立部件，体现装配/功能关系）
| 部件 | 关键尺寸 | 说明 |
|---|---|---|
| 座舱主体 | 长约 3200、最大宽 1500、最大高 1300 | 泪滴形单体壳，前段为可透视座舱盖 |
| 座舱盖 | 与壳体沿分模线留 5mm 缝隙 | 熏黑渐变夹层玻璃，后缘有可见开启铰链 |
| 涵道风扇 ×4 | 外径 900、内径 820（壁厚 40）、桨毂 180、每涵道 5 片桨叶 | 前左/前右/后左/后右对称；四涵道中心位于 X=±1400、Y=±1350 |
| 倾转臂 | 翼型截面 120×60 | 连接机身与涵道，绕 Y 轴 0–90° 倾转（悬停 90°、巡航 0°），本图统一 15° 前倾 |
| 着陆滑橇 ×1 对 | 轨距 1400、离地间隙 260 | 碳纤维弓形滑橇 |

## 材质（全 PBR）
- 壳体：珍珠白汽车漆（底色 + 金属薄片 + 清漆），粗糙度约 0.15
- 座舱盖：玻璃 BSDF，透射，IOR 1.52，用体积吸收做出烟灰色调
- 涵道外壳：3K 斜纹编织碳纤维
- 桨叶：阳极氧化深钛灰铝合金，各向异性金属
- 倾转臂：亚光深空灰
- 滑橇：拉丝铝

## 场景与地面
- 浅灰无缝影棚弧形背景地面，带轻微反射

## 灯光（HDRI 影棚环境 + 三点布光）
- 主光：左前上方大面积柔光箱，5500K
- 侧逆光：勾勒轮廓
- 底部补光：微弱，避免暗部死黑

## 相机
| 项 | 值 |
|---|---|
| 视角 | 3/4 前侧英雄视角 |
| 机位高度 | 约 1200（略低于车高，形成轻微仰视） |
| 焦距 | 50mm 全画幅等效 |
| 光圈 | f/4 |
| 传感器 | 36mm |

## 渲染
- 引擎：Cycles，采样 2048，OptiX 降噪
- 色彩管理：AgX，中性对比
- 输出：16-bit PNG，并保存 .blend
