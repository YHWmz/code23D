先看懂制作方式

这组实验通过 Claude Code 向模型提供文件和终端工具。Claude Code 是执行工具的外壳，所选模型负责发出调用。写脚本与运行脚本是两件事：模型用文件工具或终端组织 Python 代码，再用命令启动后台 Blender；脚本里的 bpy 控制物体、材质、相机和渲染。下方根据本次轨迹显示实际出现的环节。

本次使用的工具

这些工具各自在做什么？

Read：读取文本或把图像交给模型查看。Write：创建或覆盖文件。Edit：替换文件中的指定片段。Bash：执行终端命令，可写脚本、启动 Blender、运行 FFmpeg、读取日志或检查进程。Grep / Glob：搜索文件内容或查找路径。因此，Bash 调用次数不能直接当作建模次数或渲染次数。
